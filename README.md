# ICESEE

ICESEE (ICE ShEet State and Parameter Estimator) is a data assimilation software framework designed for coupling with ice-sheet, climate, and geophysical models such as ISSM, Icepack, and idealized models such as the three-variable Lorenz system (the historical example directory is named `lorenz96`). It provides a modular and extensible platform for ensemble forecasting, state estimation, parameter estimation, and uncertainty quantification across a wide range of scientific modeling applications.

---

## What is ICESEE?

ICESEE (ICE ShEet state and parameter Estimator) is a scalable ensemble-based data assimilation framework designed for coupling with ice-sheet, climate, and geophysical models such as ISSM, Icepack, and idealized systems like the Lorenz system.

ICESEE provides a modular and extensible scientific computing infrastructure for ensemble forecasting, uncertainty quantification, and parameter estimation workflows in large-scale environmental modeling.

The framework supports:
- Ensemble-based data assimilation methods
- Distributed-memory HPC execution
- Cloud-enabled scientific workflows
- Cross-language model coupling

### ICESEE on CryoStack

ICESEE is available through [CryoStack](https://cryostack.eas.gatech.edu/index.html), Georgia Tech's integrated platform for cryosphere modeling, data assimilation, scientific visualization, and HPC-enabled research. The CryoStack ICESEE interface supports state estimation, parameter inference, and ensemble-based data-assimilation workflows while providing a consistent path from browser-based configuration to local, remote, HPC, or cloud execution resources.

The [student and developer handbook](docs/handbook/README.md) documents the inspected `features_debug` implementation at commit `3748e416d3a8120cc860119bd7224c6f9ad41ff7`: [first run](docs/handbook/student-tutorial.md), [parallelization modes](docs/handbook/parallelization-modes.md), [architecture](docs/handbook/architecture.md), [analysis mathematics](docs/handbook/numerics.md), [literature](docs/handbook/literature.md), [configuration](docs/handbook/configuration.md), [HPC and containers](docs/handbook/deployment.md), [production and recovery](docs/handbook/operations.md), and [testing](docs/handbook/testing-and-contributing.md). The [technical-report preprint source](paper/production-report/README.md) explains the updated developments and their validation limits.

Use a unique output directory for a fresh run. Configuration loading can remove an existing `data_path`; `restart_enabled` alone does not protect it. Follow the documented explicit resume path before touching a valuable run. The [wiki](https://github.com/ICESEE-project/ICESEE/wiki) provides task-oriented entry points.

## Key Features

- Modular ensemble-based data assimilation framework
- State and parameter estimation capabilities
- Cross-language scientific model coupling
- Scalable HPC and distributed-memory workflows
- HDF5/NetCDF-based scientific data pipelines
- Containerized and cloud-enabled execution
- Extensible APIs for integrating external models
- Support for uncertainty quantification and ensemble forecasting
- Reproducible scientific computing infrastructure
